# Sonic MP3

تطبيق أندرويد لتحويل ملفات الوسائط المحلية إلى MP3 وإدارة تنزيل الملفات المباشرة المصرح بها.

## المواصفات
- Kotlin + Jetpack Compose + Material 3.
- تصميم داكن مع واجهة عربية/إنجليزية.
- Android 11 (API 30) أو أحدث.
- اختيار ملفات الصوت والفيديو من الهاتف.
- إعداد جودة مستهدفة: 128 / 192 / 256 / 320 kbps.
- تنزيل روابط HTTP/HTTPS المباشرة المصرح بها عبر Android Download Manager.
- GitHub Actions يبني APK تجريبياً عند كل push إلى main أو عبر Run workflow.

## البناء من GitHub
1. افتح تبويب Actions.
2. اختر Sonic MP3 Android CI.
3. اضغط Run workflow أو انتظر اكتمال البناء بعد أي push.
4. افتح نتيجة التشغيل ثم نزّل Artifact باسم Sonic-MP3-debug-apk.

## البناء محلياً
يتطلب JDK 17 و Android SDK 35 و Gradle 8.9:
```bash
gradle assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## حدود الإصدار 0.1.0
واجهة اختيار الملفات وجودة الإخراج والتنزيل المباشر موجودة. محرك الترميز MP3 الفعلي ومكتبة الصوت وإدارة تقدم التحويل ما زالت مراحل تطوير لاحقة؛ لا يعتبر زر التحويل في هذا الإصدار منتجاً لملف MP3 بعد.

لا يحتوي التطبيق على آلية لاستخراج الصوت من روابط YouTube أو تجاوز قيود المنصة. استخدم فقط الوسائل التي تسمح بها المنصة والملفات والمصادر التي تملك حق تنزيلها.
