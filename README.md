# YouTube to MP3 Converter (Android)

تطبيق أندرويد مفتوح المصدر لتحويل فيديوهات يوتيوب إلى ملفات صوتية MP3 بواجهة عصرية مبنية بـ Jetpack Compose.

## ✨ الميزات
- واجهة مستخدم عصرية (Material 3) مع دعم الوضع الداكن والألوان الديناميكية.
- تحويل الفيديوهات إلى MP3 بجودة عالية.
- إمكانية تضمين صورة الغلاف والبيانات الوصفية (Metadata).
- معالجة التنزيلات في الخلفية باستخدام WorkManager.
